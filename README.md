# 🦉 SSC 2027 · স্মার্ট স্টাডি সঙ্গী (PWA)

> “এক ধাপ করে পড়ো। পারফেকশনের চেয়ে অগ্রগতি বেশি গুরুত্বপূর্ণ।”

SSC 2027 শিক্ষার্থীদের জন্য একটা মোবাইল অ্যাপ (PWA)। এতে আছে গেমের মতো ৯০ দিনের প্ল্যান, ফোকাস টাইমার, ভুলের খাতা, পরীক্ষার হিসাব, অ্যালার্ম, মজার রোস্ট নোটিফিকেশন আর স্কুলভিত্তিক লিডারবোর্ড। অ্যাপটা মোবাইলে **ইনস্টল করা যায়** এবং **ইন্টারনেট ছাড়াও চলে**।

| 🥇 প্রতিযোগিতা জোন | নিজের স্কুলের র‍্যাঙ্কিং, স্কুল বনাম স্কুল, সারাদেশ আর বন্ধুদের গ্রুপ (কোড দিয়ে যোগ দেওয়া যায়)। সাপ্তাহিক আর সর্বমোট দুই হিসাবই দেখা যায়। |
| 🧮 জিপিএ ক্যালকুলেটর | প্রোফাইল → পড়াশোনা। বিভাগ অনুযায়ী বিষয় নিজে থেকেই আসে। নম্বর অথবা গ্রেড দিয়ে হিসাব করা যায়। ৪র্থ বিষয়ের বোনাস আর F হলে ফেলের নিয়ম মেনে চলে। কোন বিষয়ে A+ পেতে আর কত নম্বর লাগবে, সেটাও দেখায়। |
| 🏛️ এসএসসি রেজাল্ট | সরকারি রেজাল্ট পোর্টাল, ১১টি শিক্ষা বোর্ডের ওয়েবসাইট আর SMS-এ রেজাল্ট পাওয়ার জন্য তৈরি মেসেজ (`SSC CHI 123456 2027` → 16222)। রোল আর রেজিস্ট্রেশন সেভ করে রেখে কপি করা যায়। |
| 🛡️ ফোকাস গার্ড *(শুধু APK)* | Accessibility সার্ভিস দিয়ে সোশ্যাল মিডিয়া লক করে। প্রতিটি অ্যাপের জন্য দৈনিক সময়সীমা আর খোলার অনুমোদিত সময় ঠিক করা যায়। পড়ার সময় সব অ্যাপ লক থাকে, ফোকাস টাইমার চললেও লক থাকে। লক হলে স্ক্রিনের উপর রোস্টসহ অ্যানিমেটেড ওভারলে আসে। প্রতি ১–৩ মিনিট পরপর “এখনো পড়ার সময়!” খোঁচা দেয়। “আর ২ মিনিট” ছাড় দিনে সীমিত বার পাওয়া যায়, কড়া মোডে একবারও না। |
| 📲 Android অ্যাপ | একই ওয়েব অ্যাপ APK-এর ভেতরে থাকে। এতে বাড়তি আছে ফোকাস গার্ড, অ্যাপ বন্ধ থাকলেও সিস্টেম অ্যালার্ম (রিস্টার্টের পরেও চলে), ফাইল সেভ আর অ্যাপের ভেতরেই রেজাল্ট সাইট খোলা। |
| ✏️ কাস্টম প্ল্যান | রোডম্যাপ → “কাস্টম প্ল্যান” ট্যাব (প্রোফাইল → পড়াশোনা থেকেও খোলা যায়)। প্রতিটি সপ্তাহের যেকোনো কাজের সময় বদলানো, অন্য দিনে সরানো, উপরে-নিচে সাজানো বা লুকানো যায়। নিজের কাজও যোগ করা যায়: বিষয়, অধ্যায়, ধরন, সময়, আর একসাথে কয়েক দিনে রিপিট। মূল প্ল্যান অক্ষত থাকে, এক ট্যাপে সপ্তাহ বা পুরো প্ল্যান রিসেট করা যায়। লিডারবোর্ড যেন ন্যায্য থাকে, তাই নিজের কাজে কম XP (দিনে সর্বোচ্চ ১৫০) মেলে, আর সপ্তাহের ৬০%-এর কম মূল কাজ রাখলে রকেট বোনাস মেলে না। |
| ✍️ রাইটিং তালিকা *(নতুন v1.3)* | বাংলা ২য় পত্রের নির্মিতি (অনুচ্ছেদ, চিঠি/দরখাস্ত, সারাংশ, ভাবসম্প্রসারণ, সংবাদ প্রতিবেদন, প্রবন্ধ রচনা) আর ইংরেজির রাইটিং অংশ (Paragraph, Completing Story, Rearrange, Graph, Letter/E-mail/Dialogue, Application, CV, Composition)। এগুলোতে প্ল্যান আর "বোর্ড বই/টেস্ট পেপার" বলে দেয় না। শিক্ষার্থী নিজে প্রতি লাইনে একটা করে নাম লেখে (যেমন ১০টা Paragraph, সর্বোচ্চ ৩০টি), চাইলে জনপ্রিয় টপিকে ট্যাপ করেও যোগ করতে পারে। তারপর কোন সপ্তাহ থেকে কোন সপ্তাহ আর প্রতিটায় কত সময় লাগবে বেছে নেয়। অ্যাপ নিজে সেগুলো সপ্তাহে ভাগ করে দিনের প্ল্যানে বসিয়ে দেয়। MCQ, ব্যাকরণ আর পাঠ্যবইয়ের অংশ আগের মতো থাকে, সেখানে কাজের ধরন এখন "পাঠ + MCQ / প্রশ্ন অনুশীলন"। তালিকা খোলা যায় তিন জায়গা থেকে: রোডম্যাপ → কাস্টম প্ল্যান, প্রোফাইল → পড়াশোনা, আর বিষয়ের পাতা থেকে। |
| ⚡ পারফরম্যান্স মোড | প্রোফাইল → সেটিংস। **অটো** মোডে Android অ্যাপ আর কম RAM-এর ফোনে নিজে থেকেই স্মুথ মোড চালু হয়। **স্মুথ** মোডে সাজসজ্জার অ্যানিমেশন কয়েকবার চলে থেমে যায়, আর ব্লার বা স্ট্যাগার ইফেক্ট বন্ধ থাকে। **ফুল** মোডে সব অ্যানিমেশন চলে। অ্যাপ ব্যাকগ্রাউন্ডে গেলে সব অ্যানিমেশন বন্ধ থাকে। |
| 🔐 গোপনীয়তা | সার্ভারে (Google Sheet) যায় শুধু প্রোফাইল আর পয়েন্ট। বাকি সব ডেটা ফোনেই থাকে। মোবাইল নম্বর কখনো লিডারবোর্ডে দেখানো হয় না। |

## 🚀 ধাপ ১: Google Sheet সার্ভার সেটআপ (৫ মিনিট)

1. **sheets.new** এ গিয়ে একটা নতুন Google Sheet খোলো। নাম দাও, যেমন `SSC 2027 Students`।
2. মেনু থেকে **Extensions → Apps Script** খোলো।
3. সেখানকার পুরোনো কোড মুছে `backend/Code.gs` ফাইলের পুরো কোড পেস্ট করো, তারপর 💾 Save চাপো।
4. উপরের ফাংশন লিস্ট থেকে **`setup`** বেছে **▶ Run** চাপো।
   - প্রথমবার Google অনুমতি চাইবে। Advanced → Go to project → Allow চাপো।
   - এতে শিটে `Students` আর `Squads` নামে দুটো ট্যাব তৈরি হবে।
5. **Deploy → New deployment** এ যাও।
   - ⚙️ আইকন থেকে **Web app** বেছে নাও।
   - Execute as: **Me**
   - Who has access: **Anyone**
   - তারপর **Deploy** চাপো এবং **Web app URL** কপি করো (শেষে `/exec` থাকবে)।
6. `js/config.js` ফাইল খুলে URL বসাও:
   ```js
   window.SSC_CONFIG = {
     API_URL: 'https://script.google.com/macros/s/AKfycb.../exec',
     VERSION: '1.0.0'
   };
   ```
7. ঠিকমতো কাজ করছে কিনা দেখতে ব্রাউজারে `URL?action=ping` খোলো। `{"ok":true,...}` দেখালে সার্ভার রেডি ✅

> 🔁 পরে `Code.gs` বদলালে **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** করতে হবে। এভাবে করলে URL একই থাকে।

**শিটে যা থাকবে:** uid, নাম, রোল, স্কুল, জেলা, মোবাইল, বিভাগ, XP, লেভেল, স্ট্রিক, সাপ্তাহিক XP আর গ্রুপ কোড।
`token` কলামটা লুকানো থাকে। এটা প্রতিটি ডিভাইসের গোপন চাবি, তাই কাউকে শেয়ার করবে না।

> সার্ভার সেট না করলেও অ্যাপের সব ফিচার চলবে। শুধু লিডারবোর্ডে ডেমো ডেটা দেখাবে।

## 🌐 ধাপ ২: অ্যাপ অনলাইনে তোলা (ফ্রি)

## 🤖 Android APK — GitHub দিয়ে বিল্ড (কম্পিউটারে Android Studio লাগবে না)

APK-এর ভেতরে এই একই ওয়েব অ্যাপ থাকে, সাথে থাকে **ফোকাস গার্ড** (সোশ্যাল মিডিয়া লক) আর নিশ্চিত অ্যালার্ম। বিল্ডের সময় রিপোর ওয়েব ফাইলগুলো নিজে থেকেই APK-তে কপি হয়ে যায়, তাই ওয়েব আর অ্যাপ সবসময় একই কোডে চলে।

### ১. রিপো তৈরি
1. GitHub-এ নতুন রিপো খোলো, যেমন `ssc2027-app`। Public বা Private, দুটোই চলবে।
2. **এই ফোল্ডারের ভেতরের সব কিছু** (`index.html`, `js/`, `android/`, `.github/` …) রিপোর **রুটে** আপলোড করো। `ssc2027-app` ফোল্ডারটা নিজে আপলোড করবে না, শুধু ভেতরের জিনিসগুলো।
   - `.github` ফোল্ডারটা লুকানো থাকে। ওয়েবসাইট থেকে আপলোড করলে Upload files-এ ফোল্ডারসহ টেনে আনো। অথবা git ব্যবহার করো:
   ```bash
   cd ssc2027-app
   git init && git add . && git commit -m "SSC 2027 v1.3"
   git branch -M main
   git remote add origin https://github.com/<ইউজারনেম>/ssc2027-app.git
   git push -u origin main
   ```
3. Push করার পর **Actions** ট্যাবে “Build Android APK” চলতে শুরু করবে, শেষ হতে ~৫ মিনিট লাগে। শেষ হলে রানের পেজে নিচে **Artifacts → SSC2027-…-apk** থেকে APK ডাউনলোড করো।

### ২. নিজের সাইনিং কী (জরুরি, একবারই করতে হয়)
কী ছাড়া প্রতিবার আলাদা অস্থায়ী কী দিয়ে সাইন হয়। তখন নতুন APK পুরনোটার উপর **আপডেট হিসেবে ইনস্টল হবে না**।
1. যে কম্পিউটারে Java আছে, সেখানে চালাও: `bash android/make-keystore.sh`
2. এটা `ssc2027-release.jks` ফাইল বানায় আর একটা লম্বা base64 টেক্সট দেখায়। **.jks ফাইল আর পাসওয়ার্ড নিরাপদে রেখে দাও।** রিপোতে আপলোড করবে না, `.gitignore` এমনিতেই আটকে রাখে।
3. GitHub রিপো → **Settings → Secrets and variables → Actions → New repository secret**:

| Secret নাম | মান |
|---|---|
| `SSC_KEYSTORE_BASE64` | স্ক্রিপ্ট যে লম্বা টেক্সট দেখিয়েছে, পুরোটা |
| `SSC_KEYSTORE_PASSWORD` | পাসওয়ার্ড |
| `SSC_KEY_ALIAS` | `ssc2027` |
| `SSC_KEY_PASSWORD` | পাসওয়ার্ড (একই) |

এরপর থেকে প্রতিটি বিল্ড তোমার কী দিয়ে সাইন হবে।

### ৩. ছাত্রছাত্রীদের জন্য ডাউনলোড লিংক (Release)
1. নতুন ভার্সন রিলিজ করতে ট্যাগ push করো: `git tag v1.3.0 && git push origin v1.3.0`। অথবা GitHub → Releases → *Draft a new release* → ট্যাগ `v1.3.0` দিয়ে করো।
2. Workflow নিজে থেকেই Release তৈরি করে `SSC2027.apk` যোগ করে দেবে।
3. স্থায়ী লিংক সবসময় সর্বশেষ ভার্সন দেয়: `https://github.com/<ইউজারনেম>/<রিপো>/releases/latest/download/SSC2027.apk`
4. লিংকটা `js/config.js`-এর `APK_URL`-এ বসাও। তাহলে ওয়েব অ্যাপের **প্রোফাইল → অ্যাপ ইনস্টল করো** পেজে সরাসরি “APK ডাউনলোড করো” বাটন দেখাবে। (Release পেতে রিপো Public হতে হবে, নইলে লিংক খুলবে না।)

### ৪. ফোনে ইনস্টল ও ফোকাস গার্ড চালু
1. APK খোলো। “অজানা উৎস / Install unknown apps” চাইলে **Allow** দাও, তারপর **Install** চাপো। Play Protect সতর্ক করলে “Install anyway” চাপো।
2. অ্যাপে **প্রোফাইল → ফোকাস গার্ড** খোলো, সুইচ চালু করো, তারপর **Accessibility → SSC 2027 ফোকাস গার্ড → On** করো।
   - **Android 13+**-এ সুইচ ধূসর হয়ে থাকলে বা “Restricted setting” লেখা দেখালে: Settings → Apps → SSC 2027 → উপরের ⋮ → **Allow restricted settings**। তারপর আবার চেষ্টা করো। সাইডলোড করা অ্যাপের জন্য Android নিজেই এই নিয়ম রেখেছে।
3. **অ্যাপ যোগ করো** দিয়ে ফেসবুক, টিকটক, ইউটিউব ইত্যাদি বেছে নাও। প্রতিটির জন্য দৈনিক মিনিট আর খোলার অনুমোদিত সময় ঠিক করো। তারপর পড়ার সময় আর খোঁচার বিরতি (১/২/৩/৫ মিনিট) সেট করো।
4. Xiaomi, Oppo, Vivo, Realme ফোনে **ব্যাটারি অপটিমাইজেশন বন্ধ** করো (পারমিশন তালিকায় বাটন আছে)। “Autostart” চালু রাখো, নইলে ফোন গার্ডকে বন্ধ করে দিতে পারে।
5. **টেস্ট করে দেখো → লক স্ক্রিন / খোঁচা** চাপলে সাথে সাথেই রোস্ট ওভারলে দেখাবে।

> ওয়েব থেকে অ্যাপে অগ্রগতি নিতে: ওয়েবে **প্রোফাইল → ব্যাকআপ ডাউনলোড** করো, তারপর অ্যাপে **রিস্টোর** করো। অথবা অ্যাপের শুরুতে আইডি আর মোবাইল দিয়ে সার্ভার থেকে ফিরিয়ে আনো।

**গোপনীয়তা:** ফোকাস গার্ড শুধু দেখে কোন অ্যাপ এখন সামনে আছে। স্ক্রিনের লেখা পড়ে না (`canRetrieveWindowContent=false`), আর ইন্টারনেটে কিছুই পাঠায় না।

**লোকাল বিল্ড (ঐচ্ছিক):** JDK 17 আর Android SDK থাকলে `cd android && ./gradlew assembleDebug` চালাও। APK পাওয়া যাবে `android/app/build/outputs/apk/debug/`-এ।
